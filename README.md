# tinyleed.com

Static one-page site for [tinyleed.com](https://tinyleed.com). Plain HTML and CSS, no build step; Vercel serves the files as they are.

- `index.html`: the page
- `tinyleed-mark.svg`: logo mark (also the favicon)
- `apple-touch-icon.png`: home screen icon
- `qleenio-mark.svg`, `qleenio-logo-dark.svg`: qleenio brand files used on the page
